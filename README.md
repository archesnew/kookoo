# KOO KOO — стартовый пакет v0.1

Telegram Mini App: коллекционирование голубей, кормление, яйца, селекция, социальная игра.

Этот архив содержит проектную документацию и визуальные референсы, а не готовый код игры. Все численные параметры в ECONOMY.md — тестовые, если не сказано иначе.

## Старт в Codex

1. Распаковать архив в новую папку проекта, открыть её в Codex (или добавить файлы в новый репозиторий).
2. Передать запрос ниже.
3. Запустить локальный прототип по инструкции, которую Codex добавит в README приложения.

```text
Прочитай AGENTS.md, GDD.md, ECONOMY.md, DESIGN.md и ROADMAP.md. Изучи images в references/ (это референсы, не готовые спрайты).
Реализуй только этап 0 из ROADMAP.md: мобильный React + TypeScript прототип KOO KOO с тремя экранами (загрузка, голуби, яйца), локальным сохранением и единой тестовой игровой логикой. Сделай кормление, сброс стоимости через 8 часов, очередь яиц, merge до 12 уровня и разбитие с наградами. Не реализуй деньги, NFT, платные случайные награды, маркет или мультиплеер. Не придумывай окончательные правила: используй помеченные тестовые параметры из ECONOMY.md, вынеси их в конфигурацию. Сохрани фирменный минимализм, адаптивность и внешний вид из references/home.png, но не используй скриншот целиком как интерфейс. Напиши тесты для экономики и сохранения прогресса. Добавь инструкции установки, запуска и тестирования. Если графика ещё не разделена на слои, используй явно обозначенные временные ассеты. Не утверждай, что они являются готовыми модульными спрайтами.
```
